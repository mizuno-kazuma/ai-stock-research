# 02. Recommendations

## Purpose

The screen where the product's core output lives. It lists the recommendation cards generated by the
Strategist and approved or revised by the Critic, with the full thesis, the mandatory bear case, the
reason codes, the citations that back each claim, and the historical hit rate of similar past cases.

This screen carries the highest risk of misleading the user, so the layout is deliberately built to
make the negative side of every recommendation impossible to miss. The bear case is not a footnote,
not a tooltip, and not collapsed. A card whose bear case is missing cannot be rendered; the data
model forbids it and the UI treats its absence as a defect to surface, not a state to design for.

Rejected recommendations are visible behind a filter, not deleted. Seeing what the Critic threw out
is how the user calibrates trust in the system.

## Route

`/recommendations`

Query parameters, all synced to the URL so a view is shareable and survives reload:

| Param | Values | Default |
| --- | --- | --- |
| `market` | `JP`, `US` | global market setting |
| `as_of` | ISO date | latest available |
| `horizon` | `H5`, `H20`, `all` | `H20` |
| `action` | `watch`, `accumulate`, `reduce`, `avoid`, `all` | `all` |
| `conviction` | `low`, `medium`, `high`, `all` | `all` |
| `critic_verdict` | `approved`, `revised`, `rejected`, `all` | `approved,revised` |
| `sector` | sector code | none |
| `sort` | `total_score`, `expected_ret`, `conviction`, `generated_at` | `total_score` |
| `rec_id` | ULID | none, expands and scrolls to that card |

## Layout

### Desktop (>= 1280px)

12-column grid. Two-pane layout with a sticky filter rail.

| Region | Columns | Behavior |
| --- | --- | --- |
| `FilterRail` | 1-3 | Sticky, top offset `--header-height` + `--space-6`, own scroll |
| `RecommendationList` | 4-12 | One `RecommendationCard` variant `full` per row, `--space-6` between cards |

Card max width `--prose-max-width` is not applied to the card itself, but the thesis and bear-case
paragraphs inside are capped at `68ch` for readability.

### Tablet (768px - 1279px)

8-column grid. The filter rail collapses into a `FilterBar` above the list with a "絞り込み" button
opening a right `Sheet`. Cards span all 8 columns.

### Mobile (< 768px)

Single column. `FilterBar` becomes a horizontal scrolling chip row showing active filters plus a
filter button that opens a bottom sheet.

`RecommendationCard` variant `full` on mobile reflows:

- Header stacks to two lines: ticker + name, then badges wrapped.
- `ForecastValue` becomes a two-line block: point estimate on the first line, interval and hit rate
  on the second.
- `FactorRadar` is replaced by the factor score table (radar charts are unreadable below 320px).
- `CitationList` items collapse the quote to 3 lines with an in-place expand.
- The bear-case section stays fully expanded. This is the one thing that must not be collapsed on
  small screens.
- Action buttons become a sticky bottom row within the card, 44px tall.

### Reason codes

Rendered as `ReasonCodeChip` in the order returned by the API, which intermixes tones. Do not sort
positives first.

```
[セクター内で割安] [会社予想の上方修正] [12ヶ月モメンタム強い] [為替が追い風]
[新規リスクの開示] [決算発表が近い]
```

Negative and warning chips use `--status-danger-bg` / `--status-warning-bg` at the same size, same
font weight, and same opacity as positive chips.

Example content:

```
強気論拠
北米向け販売が会社計画を上回り、2027年3月期の営業利益予想が5%上方修正された（8月8日開示、
決算短信 p.3）。セクター内でPERは下位25%圏にあり、ROICは12.4%で同セクター中位を上回る。
為替前提が1ドル148円のため、152円台の現状は上振れ要因となる。

弱気論拠
上方修正の主因は為替効果で、数量ベースの改善は前年同期比+1.2%にとどまる（決算短信 p.7）。
円高に転じた場合、上方修正分の大半が消える構造にある。加えて北米では競合の値引き圧力が
続いており、下期の販売奨励金の増加リスクが開示されている（有価証券報告書 p.24）。
セクター内モメンタムは強いが、これは過去3ヶ月の円安を織り込んだ結果であり、
為替が反転すれば同じ経路で逆回転する。

この見立てを捨てる条件
1ドル145円を下回る、または月次販売台数が2ヶ月連続で前年割れとなった場合、
上方修正の前提が崩れるため本推奨は無効とする。
```

The bear-case panel uses `--status-warning-bg` with a 2px `--status-warning` left border. Same
typography as the thesis. No collapse control. No reduced opacity.

## States

### Loading

Three skeleton cards at 640px height on desktop, 820px on mobile. The skeleton reproduces the
section structure including a placeholder block where the bear case will be, so the layout does not
jump.

### Empty (no recommendations for the day)

| Element | label_ja |
| --- | --- |
| Title | 本日の推奨はありません |
| Body | 条件を満たす銘柄が見つかりませんでした。ユニバースフィルタが厳しすぎるか、Criticが全件を却下した可能性があります。 |
| Detail | 生成 12件 → 却下 12件（引用の不一致 8件、弱気論拠の実質性不足 4件） |
| Action 1 | 却下された推奨を表示 |
| Action 2 | エージェントコンソールで詳細を見る → `/agent` |

Showing the rejection breakdown is important. "No recommendations" without a reason looks like a
bug.

### Empty (filters too narrow)

| Element | label_ja |
| --- | --- |
| Title | 条件に一致する推奨がありません |
| Body | 12件の推奨のうち、現在の絞り込み条件に一致するものはありません。 |
| Action | 条件をリセット |

### Not-ready

```
2026年8月23日の推奨はまだ生成されていません。
Strategistの実行予定は 06:35 (JST) です。最新の利用可能日は 2026年8月22日です。
```

### Partial data

| Failing part | Behavior |
| --- | --- |
| LLM cost cap reached during Researcher | Cards render with `定性 —` and a card-level note: `LLMの日次予算に達したため、定性評価を含まずに生成されています。定量スコアのみに基づく推奨です。` The card is still valid and still has a bear case, generated from quantitative risk factors |
| Citation verification incomplete | Citation items show `未検証` in `--status-neutral` with the note `Criticの検証が完了していません` |
| Past performance unavailable | `類似条件の過去実績: 算出に必要なサンプルがまだありません（運用開始から46営業日）` |
| Factor scores partially missing | Missing rows render `—` with a caption listing which inputs were unavailable |
| Freshness stale for this ticker | Card shows a `DATA_STALE` warning chip and the freshness row highlights the stale source |

### Error

Section-level error inside the list region, page chrome intact:

| Element | label_ja |
| --- | --- |
| Title | 推奨を読み込めませんでした |
| Body | 推奨データの取得に失敗しました。 |
| Detail | `GET /api/v1/recommendations` → 500 |
| Action | 再試行 |

### Offline

Cached recommendation cards render fully, including bear cases and citations, because they were
prefetched. The filing links are disabled with a tooltip `オフラインでは資料を開けません`. Feedback
buttons queue via Background Sync and show `送信待ち`.

### Degraded

When the kill switch is on and today's cards were produced without the LLM, a page-level banner
reads: `LLMの停止スイッチが有効なため、本日の推奨は定量スコアのみで生成されています。`
